SELAH RTA Support

사용 안내와 자주 묻는 질문

앱 소개

SELAH RTA는 Android 기기에서 실시간으로 음압과 주파수 균형을 분석·측정하는 오디오 분석 애플리케이션입니다. 스마트폰의 내장 마이크만으로 사용할 수 있으며, 측정용 마이크와 USB 오디오 인터페이스를 연결하면 보다 전문적인 측정 환경을 구성할 수 있습니다.

기본 사용 안내

  1. 앱을 열고 마이크 권한을 허용합니다.
  2. 첫 화면에서 현재 사용 중인 마이크를 확인합니다.
  3. 측정 시작을 누릅니다.
  4. 필요한 경우 권장 범위를 표시하여 현재 측정값과 비교합니다.
  5. 측정 결과를 저장하려면 「이 측정을 기록하기」를 누릅니다. 오디오 녹음 여부는 이때 선택합니다.
  6. 기록 화면에서 리포트를 보고 CSV·소리 파일을 내보낼 수 있습니다.

지원되는 Android 환경

  • Android 스마트폰 및 태블릿
  • 마이크 권한이 필요합니다
  • 측정 중 화면이 꺼져도 측정이 이어지도록 포그라운드 서비스를 사용합니다

마이크 안내

  • 보정하지 않은 값은 참고용입니다. 휴대폰 마이크의 감도는 기기마다 다르며, 앱은 그 값을 알 수 없습니다. 기준 소음계가 있다면 설정 → 교정 마법사에서 맞춰 주세요.
  • 휴대폰 케이스가 마이크 구멍을 막을 수 있습니다. 후면 마이크를 사용할 때 특히 그렇습니다. 케이스로 인한 차이를 마이크의 특성으로 오해하지 않도록, 케이스를 벗긴 상태와 비교해 보시기 바랍니다.
  • 보정값은 기기마다 따로 저장됩니다. 내장 마이크와 USB 마이크는 감도가 수십 dB까지 차이 나므로, 기기를 바꾸면 해당 기기의 보정값이 적용됩니다.

USB 오디오 인터페이스 안내

  • ASIO는 Windows 환경에서 사용하는 오디오 드라이버 규격으로, Android에서는 사용되지 않습니다. Android는 USB Audio Class를 사용하므로, 제품 설명에 class compliant (또는 「드라이버 불필요」)라고 표기된 인터페이스는 연결하면 그대로 인식됩니다.
  • 전용 드라이버가 반드시 필요한 제품은 지원하지 않습니다. 앱 설정으로 해결할 수 있는 문제가 아닙니다.
  • 전원 공급을 확인해 주세요. 팬텀 전원(+48V)을 사용하는 인터페이스는 스마트폰 배터리만으로 전력이 부족할 수 있습니다. 기기 인식이 반복적으로 끊기거나 오디오가 불안정한 경우 전원이 공급되는 USB-C 허브를 사용해 주세요.
  • 충전 전용 케이블은 사용할 수 없습니다. 데이터 전송을 지원하는 케이블을 사용해 주세요.
  • 입력이 여러 개인 기기는 설정 → 측정 입력 채널에서 측정에 사용할 채널을 선택합니다. 입력마다 다른 마이크가 연결되어 있을 수 있으므로 채널을 섞지 않습니다.

보정(Calibration) 안내

  • 절대 음압 보정: 기준 소음계나 교정기(94 dB @ 1 kHz)와 맞추어 기준값을 설정합니다. 설정 → 교정 마법사에서 진행합니다.
  • 마이크 주파수 응답 보정: 제조사가 주는 보정 파일 (.cal · .frd · .txt)을 불러오면 마이크의 주파수 편차를 보정합니다. 설정 → 주파수 보정에서 적용합니다.
  • 주파수 보정은 RTA·Spectrum·Spectrogram에 적용되며, 큰 음압 수치에는 전대역 보정값만 반영됩니다. 앱이 이 한계를 화면에 표시합니다.

자주 묻는 질문

법에서 정한 소음 측정에 쓸 수 있습니까?

대체할 수 없습니다. 소음 평가나 작업환경측정과 같이 장비·방법·자격 요건이 정해진 측정에는 해당 요건을 갖춘 별도의 측정이 필요합니다. 이 앱과 일반 Android 기기만으로는 형식승인, 검정, 정도검사 또는 공인 교정 요건을 충족하지 않습니다. 기록을 개별 분쟁에서 자료로 쓸 수 있는지와 그 가치는 관련 법령과 해당 기관이 판단하며, JOAWORKS는 이를 보장하지도 부정하지도 않습니다 (이용약관 제4조).

측정한 값이 소음계와 다릅니다.

보정하지 않은 상태에서는 차이가 날 수 있습니다. 앱이 스마트폰 마이크의 감도를 알 수 없기 때문입니다. 교정 마법사에서 기준 소음계와 맞춰 주세요. 양쪽의 주파수 가중이 같은지(예: 둘 다 dB(A))도 함께 확인해 주세요.

측정을 시작하면 잠깐 값이 낮게 나옵니다.

시간 가중이 0에서 올라오는 과정이기 때문입니다. Fast는 약 0.4초, Slow는 약 3초가 걸립니다. 설정 → 응답 속도에서 변경할 수 있습니다.

녹음 파일은 어디에 저장됩니까?

기기 내부의 앱 전용 저장소에 저장됩니다. 다른 앱이 임의로 읽을 수 없으며, 해당 기록을 삭제하면 녹음 파일도 함께 삭제됩니다. 앱을 삭제해도 마찬가지입니다. 파일을 내보내려면 기록 화면에서 보내기를 선택해 주세요. 이때 사용자가 선택한 앱에 해당 파일에 대한 읽기 권한이 전달됩니다.

기기를 변경하면 기록은 이전되지 않습니다(백업 대상에서 제외되어 있습니다). 보관이 필요한 기록은 미리 내보내 주세요.

데이터가 JOAWORKS 서버로 전송됩니까?

전송되지 않습니다. 앱은 인터넷 권한을 요청하지 않으며, 스스로 네트워크에 접속하지 않습니다. 다만 사용자가 「보내기」를 통해 다른 앱으로 파일을 전달하는 것은 별개입니다. 자세한 내용은 개인정보처리방침을 확인해 주세요.

기록이 안 보입니다.

「이 측정을 기록하기」를 누른 측정만 저장됩니다. 측정만 하고 기록하지 않으면 저장되지 않습니다.

문의

답변까지 며칠이 걸릴 수 있습니다. 기기 모델명과 Android 버전, 문제가 발생한 상황을 함께 적어 주시면 더 빠르게 안내해 드릴 수 있습니다.
