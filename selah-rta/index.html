SELAH RTA

Real-Time Audio Analysis & Measurement Application

SELAH RTA는 안드로이드 기기에서 실시간으로 음압과 주파수 균형을 재는 오디오 분석 애플리케이션입니다. 휴대폰 내장 마이크만으로도 동작하며, USB 오디오 인터페이스와 측정용 마이크를 연결하면 정확도가 올라갑니다.

법정 측정을 대신하지 않습니다. 일반 Android 기기와 마이크로 재는 것만으로는 법령·규격이 요구하는 형식승인·검정·정도검사나 공인 교정을 갖춘 것이 아닙니다. 보정하지 않은 상태의 절대 음압은 실제와 차이가 날 수 있으므로 기준 소음계로 교정한 뒤 쓰시기를 권합니다. 자세한 내용은 이용약관 제4조를 보십시오.

주요 기능

Real-Time Audio Analysis

마이크로 들어오는 소리를 실시간으로 분석합니다.

Sound Pressure Level Measurement

SPL·Leq·MIN·MAX·순간최고. A / C / Z 주파수 가중과 Fast / Slow 시간 가중을 고를 수 있습니다.

RTA / Spectrum / Spectrogram

1/3 옥타브 31밴드, 연속 스펙트럼, 시간에 따른 주파수 변화.

Frequency Response Analysis

핑크 노이즈로 공간의 대역 균형을 확인합니다.

Feedback Detection

하울링이 의심되는 주파수 후보를 실시간으로 찾습니다.

Recording & CSV Export

측정을 기록하고 조건과 값을 CSV로 내보냅니다. 소리를 함께 담을지는 기록할 때마다 묻습니다.

Microphone Calibration

교정 마법사, 프로파일 관리, 마이크 주파수 응답 파일(.cal / .frd / .txt) 적용.

Internal / External Microphone

내장 마이크와 외부 마이크를 같은 방식으로 다루고, 보정값은 기기마다 따로 둡니다.

USB Audio Interface Support

USB Audio Class 인터페이스를 지원합니다. 여러 입력 중 잴 채널을 고를 수 있습니다.

Instrument EQ Guide

악기별로 어느 대역을 살펴야 하는지 안내합니다.

Signal Generator

순음·핑크 노이즈를 내보내 점검에 씁니다.

지원 환경

  • Android 스마트폰 · 태블릿
  • 마이크 권한 필요
  • USB Audio Class(클래스 준수) 오디오 인터페이스 지원 — 전용 드라이버가 필요한 제품은 지원하지 않습니다

개인정보

SELAH RTA는 인터넷 권한을 요청하지 않습니다. 측정값·기록·녹음 파일은 기기 안에 저장되며, 앱이 JOAWORKS 서버로 자동 전송하지 않습니다. 이용자가 「보내기」를 누르면 그 자리에서 고른 앱으로 파일이 전달됩니다. 자세한 내용은 개인정보처리방침을 보십시오.
