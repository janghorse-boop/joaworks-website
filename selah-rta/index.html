SELAH RTA

Real-Time Audio Analysis & Measurement Application

SELAH RTA는 Android 기기에서 실시간으로 음압과 주파수 균형을 분석·측정하는 오디오 분석 애플리케이션입니다. 스마트폰의 내장 마이크만으로 사용할 수 있으며, USB 오디오 인터페이스와 측정용 마이크를 연결하면 보다 전문적인 측정 환경을 구성할 수 있습니다.

SELAH RTA는 법정 측정을 대체하지 않습니다. 일반 Android 기기와 마이크만으로는 관련 법령이나 규격에서 요구하는 형식승인, 검정, 정도검사 또는 공인 교정 요건을 충족하지 않을 수 있습니다. 절대 음압은 기기의 특성과 보정 상태에 따라 실제 값과 차이가 날 수 있으므로, 필요한 경우 기준 소음계 또는 교정기를 이용한 보정을 권장합니다. 자세한 내용은 이용약관 제4조를 확인해 주세요.

주요 기능

Real-Time Audio Analysis

마이크로 입력되는 소리를 실시간으로 분석합니다.

Sound Pressure Level Measurement

SPL·Leq·MIN·MAX·순간최고 값을 표시합니다. A/C/Z 주파수 가중과 Fast/Slow 시간 가중을 선택할 수 있습니다.

RTA / Spectrum / Spectrogram

1/3 옥타브 31밴드 RTA와 연속 스펙트럼, 시간에 따른 주파수 변화를 확인할 수 있습니다.

Frequency Response Analysis

핑크 노이즈를 활용하여 공간의 주파수 대역 균형을 확인합니다.

Feedback Detection

하울링이 의심되는 주파수 후보를 실시간으로 확인할 수 있도록 지원합니다.

Recording & CSV Export

측정 결과와 측정 조건을 기록하고 CSV 파일로 내보낼 수 있습니다. 오디오 녹음 여부는 사용자가 측정 기록 시 직접 선택합니다.

Microphone Calibration

교정 마법사와 프로파일 관리를 지원하며, 마이크 주파수 응답 파일(.cal / .frd / .txt)을 적용할 수 있습니다.

Internal / External Microphone

내장 마이크와 외부 마이크를 동일한 방식으로 다루며, 보정값은 기기별로 따로 관리합니다.

USB Audio Interface Support

USB Audio Class 규격의 오디오 인터페이스를 지원하며, 여러 입력 채널 중 측정에 사용할 채널을 선택할 수 있습니다.

Instrument EQ Guide

악기별로 확인해야 할 주파수 대역을 안내합니다.

Signal Generator

순음, 핑크·화이트 노이즈, 1/3 옥타브 대역 노이즈, 스윕 신호를 출력합니다. 좌·우·양쪽 채널을 선택할 수 있어 음향 시스템 점검과 측정에 활용할 수 있습니다.

지원 환경

  • Android 스마트폰 및 태블릿
  • 마이크 권한이 필요합니다
  • USB Audio Class 규격을 준수하는 오디오 인터페이스를 지원합니다. 전용 드라이버가 필요한 제품은 지원하지 않습니다

개인정보

SELAH RTA는 인터넷 권한을 요청하지 않습니다. 측정값과 기록, 녹음 파일은 기기 안에 저장되며 JOAWORKS 서버로 자동 전송되지 않습니다. 사용자가 「보내기」를 누르면 그때 직접 선택한 앱으로 파일이 전달됩니다. 자세한 내용은 개인정보처리방침을 확인해 주세요.
