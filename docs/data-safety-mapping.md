# Google Play 데이터 보안(Data Safety) 대조표

지시서 7절. **Play Console 을 열람하지 못했다.** 따라서 마지막 열
「Console 응답」은 전부 비어 있고, **현재 신고 내용과 문서의 일치 여부는
미확인**이다. 앱은 아직 스토어에 게시되지 않았으므로 신고 자체가
존재하지 않을 수도 있다 — 그것도 확인하지 못했다.

코드 근거는 [implementation-verification.md](implementation-verification.md)
의 C01~C18 을 가리킨다(기준 커밋 `d869fdf`).

## Console 을 열었을 때 할 일

1. 현재 신고 내용을 내보내 위 표의 마지막 열을 채운다.
2. **다르면 방침이 아니라 사실을 먼저 본다** — 어느 쪽이 틀렸는지
   코드로 확인한 뒤 맞는 쪽으로 고친다.
3. 타겟층 설정이 방침의 아동 항목과 맞는지 본다.
4. 스토어의 개인정보처리방침 URL 이 `https://joaworks.com/privacy/`
   인지 확인한다.
5. 신고 예외(기기 내 처리·이용자 주도 공유)를 적용했다면 **그 판단
   근거를 여기에 적어 둔다.** 다음 심사에서 다시 설명해야 한다.
